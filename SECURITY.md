# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

When the repository is public, use a private GitHub Security Advisory. While it is private, use the repository owner's private GitHub contact channel. Include only the minimum reproduction details needed to investigate; do not attach credentials, tokens, cookies, or production data.

## Distribution safety

The repository must not contain real business Tasks, Journal entries, handoffs, verification artifacts, private MCP configuration, credentials, internal URLs, or machine-specific absolute paths.
